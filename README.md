# Traveloop ✈

Traveloop is a full-stack travel planning web application where users can create trips, manage city stops, add activities, track budget, and organize itineraries beautifully.

## Features

- User Authentication
- Create / Delete Trips
- City Stop Planner
- Activity Management
- Budget Tracking
- Responsive Mobile UI

## Tech Stack

Frontend:
- HTML
- CSS
- JavaScript

Backend:
- Flask
- SQLAlchemy

Database:
- SQLite
